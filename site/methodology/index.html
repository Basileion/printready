Reproducible scoring

Methodology

Every mesh is normalized so its longest bounding-box edge is 50 mm, then scored 0–100. Hard fail: if the mesh is not watertight or the slicer fails, the score is capped at 39.

Weight table

CheckWeightPass bar
Watertight20trimesh is_watertight
Manifold15Every edge shared by exactly 2 faces
Non-manifold edge count100 ideal; soft penalty ≤5
Self-intersections100 overlapping bodies / faces
Thin walls10≥0.8 mm at normalized scale
Slice success20OrcaSlicer emits G-code (exit 0)
Print time5Soft — vs week median when live
Support volume10Lower is better; soft

Slicer profile (phase 1)

  • OrcaSlicer 2.4.2
  • Machine: Bambu Lab A1 · 0.4 mm nozzle
  • Process: 0.20 mm Standard @BBL A1
  • Filament: Generic PLA @BBL A1

Exact profile files ship next to score JSON under /workspace/printready/scores/ on the build box.

What we do not score (yet)

Texture beauty, game-engine retopo, multi-color painting, or “looks cool on Sketchfab.” Those are someone else’s leaderboard.

Authority & freshness

Prompt pack versioned (v0.1). Pipeline dry-run dated 2026-10-30 (America/New_York). Live weekly archives will freeze prompts + raw meshes so anyone can re-score.
