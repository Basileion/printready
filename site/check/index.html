    Questions

    Is my file uploaded?

    No. It’s read by JavaScript in this tab. The file and its name never reach a server. We only count anonymous events (“a file was checked”, overall pass/warn/fail), no cookies.

    Does a pass mean it will print?

    No. These are geometry checks only, not a slicer run. Thin walls, self-intersections, overhangs and supports aren’t checked here. Our benchmark scores also slice every mesh in OrcaSlicer 2.4.2 on a Bambu A1 / PLA profile.

    Are these the same checks you run on AI generators?

    Partly, and exactly where it says so. Watertight, non-manifold edge count, part count, zero-area (export padding) faces and bed contact use the same definitions and thresholds as rubric v0.2. On the 12 published Hunyuan3D-2 and Hunyuan3D-2.1 benchmark meshes, scaled to 50 mm (“Resize longest edge to 50”), this page gives the same numbers as our scorer. Wall thickness, hull fill, tree supports and slice success need the full pipeline.

    “I just budget 20 minutes in Blender per model.”

    Fair. This tells you in seconds whether those 20 minutes are needed, and which menu to open. Clean files go straight to the slicer.
